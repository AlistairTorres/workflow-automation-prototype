# Workflow Automation Prototype

A small browser prototype for moving tasks through **To do**, **In progress** and **Done**.

## What it demonstrates

- Semantic HTML and keyboard-friendly controls
- Drag-and-drop movement between workflow stages
- Persistent task state using browser local storage
- A small, dependency-free JavaScript implementation
- Responsive layout for narrow screens

## Run locally

Open taskflow.html in a modern browser. No build step or package installation is required.

The prototype stores tasks in the browser under the workflow-board.tasks key. Clearing site data resets the board.

## Scope

This is a learning project for client-side interaction and workflow state. It is intentionally not presented as a production task-management service, team workspace or automation platform.
